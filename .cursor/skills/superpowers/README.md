# Superpowers (vendored)

The skills in the parent directory (`.cursor/skills/<name>/SKILL.md`), including their helper files, are copied from [obra/superpowers](https://github.com/obra/superpowers) v7.0.1 (`2ce8aa15d05bd57213e6f746f953aafb7ded7a8b`, 2026-10-21).

License: MIT. Copyright (c) 2025 Jesse Vincent. The full text is [`LICENSE`](LICENSE) in this directory.

Local Tusky notes were added on top of the upstream text. They do not replace it.

- `brainstorming` — a headless agent with no human in the loop makes reasonable assumptions, writes them down, and proceeds
- `finishing-a-development-branch` — open or update a pull request; do not merge and do not push to `master`
- `using-superpowers` and `using-git-worktrees` — `COORDINATION.md` and the `pedro/` / `kelvyn/` branch prefixes win

`COORDINATION.md` overrides every skill. See `.cursor/rules/agent-skills.mdc`.

Pedro can install the same skills from Cursor's plugin marketplace instead of this tree. In Cursor Agent chat:

```text
/add-plugin superpowers
```

Or search for "superpowers" in the plugin marketplace.
